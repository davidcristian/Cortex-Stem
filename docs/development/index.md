# Development

This folder holds the detail behind the engineering rules in [AGENTS.md](../../AGENTS.md): what
each part of the repository holds, how a task is briefed and reported, the checks a change must
pass, the rules for the Windows code and the frontend, and the reference lists the rules point to.

- [repository-map.md](repository-map.md): what each top-level directory and crate holds.
- [briefs-and-reports.md](briefs-and-reports.md): what a task brief and a worker report contain.
- [verification-ladder.md](verification-ladder.md): the commands of the checks a change must pass.
- [windows-rules.md](windows-rules.md): the rules for the Win32 code in `stem-platform`.
- [frontend-rules.md](frontend-rules.md): the rules for the Svelte and TypeScript code in `ui/`.
- [dependency-policy.md](dependency-policy.md): what adding a crate, feature or package needs.
- [failure-modes.md](failure-modes.md): mistakes to avoid when working in this repository.
- [banned-words.md](banned-words.md): the words prose may not use, with what to write instead.
